GitHub 연결

저장 버튼을 누르면 설정과 업로드한 이미지가 kive 저장소에 커밋됩니다. 토큰은 이 브라우저 탭에서만 사용하며 서버로 전송하지 않습니다.

GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens에서 생성하세요. Repository access는 kive-site만 선택, Contents 권한은 Read and write로 설정하면 됩니다. 토큰을 다른 사람과 공유하지 마세요.

연결 전

포트폴리오 이미지

이미지를 업로드하면 portfolio/ 폴더에 저장하고 공개 페이지 갤러리에 반영합니다. 여러 장 선택할 수 있어요.

직접 정렬하려면 아래 작품 카드의 ↑ ↓ 버튼으로 순서를 바꾼 뒤 포트폴리오 순서 저장을 눌러 주세요.

포트폴리오 카테고리 관리

카테고리를 추가하고 ↑ ↓ 버튼으로 공개 페이지에 표시될 순서를 정할 수 있어요. 기존 카테고리를 삭제하면 해당 카테고리의 작품은 미분류가 되므로, 삭제 전 작품 분류를 변경해 주세요.

작업 일정

날짜를 선택한 뒤 상태를 고르고 적용하세요. 적용한 변경은 아래 저장 버튼을 눌러야 공개 사이트에 반영됩니다.

날짜를 선택하면 해당 날짜의 현재 상태가 표시됩니다.
고급 설정: 일정 데이터(JSON)

필요한 경우에만 직접 수정하세요. 날짜 형식은 YYYY-MM-DD, 상태는 available(가능), closed(마감), off(휴무)입니다.

공지사항

아래 JSON에서 공지 제목과 본문을 수정하거나 항목을 추가·삭제할 수 있습니다. 본문은 lines 배열에 한 줄씩 입력하세요.

견적 옵션

기본 작업은 하나를 선택하고, 추가 옵션은 여러 개 선택하는 구조입니다. price는 원 단위, purposes의 multiplier는 용도별 배수입니다.

문의 양식

현재 문의 양식의 필드 이름과 안내 문구를 수정할 수 있습니다. 키는 기존 필드와 연결되어 있으므로 키 이름은 바꾸지 마세요.

저장 및 배포

저장 시 site-data.json에 커밋됩니다. GitHub Pages가 자동으로 다시 배포하며 반영까지 1~2분 걸릴 수 있습니다.

저장소 연결 후 데이터를 수정하세요.
